## About Listening

**Listening** is a Windows desktop app built to make spoken content easier to understand across languages. It focuses on real-time audio translation and multilingual communication, with workflows for listening to app audio and interpreting two-way conversations.

The goal is simple: make language barriers less disruptive while you work, watch, learn, or communicate.

## The experience

| | Capability | What it is for |
|:--:|---|---|
| 🎧 | **App Audio** | Translate audio played by desktop applications. |
| 🗣️ | **Two-Way Interpreter** | Support conversations where people speak different languages. |
| ⚙️ | **Models & Setup** | Configure available translation models and app preferences. |
| 🧾 | **History** | Review previous translation activity. |
| 🩺 | **Diagnostics** | Inspect app status when troubleshooting. |

> Listening is under active development. Features and behavior may change between preview builds; check the release notes for the exact contents of each version.
